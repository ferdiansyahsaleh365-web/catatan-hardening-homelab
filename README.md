# Catatan Hardening Home Lab

Repo ini berisi catatan belajar saya mengamankan home server pribadi
yang baru dibuat dan masih "polos", artinya masih banyak celah keamanan bawaan.

*Hardening* adalah proses menutup celah-celah itu supaya server lebih susah
ditembus. Analgoginya seperti rumah baru: pintunya sudah ada, tapi masih perlu
gembok, kunci jendela, dan kamera.

# About my Server
Saya menggunakan laptop bekas dengan merk "Thinkpad T470"
Sistem Operasi nya yaitu Ubuntu Desktop 26.04
Untuk Mengakses jarak jauh saya menggunakan Tailscale
